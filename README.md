# IV.II What Data We Collect

NKRP Bot collects only the minimum information reasonably necessary for the operation of its services.

The following categories of information may be collected:

### A. User ID

Discord User IDs are collected and stored.

Examples of usage include:

* Linking users to roleplay characters.
* Tracking roleplay progression.
* Managing inventories.
* Maintaining economy balances.
* Synchronizing player records.
* Preventing duplicate registrations.

User IDs serve as the primary identifier within NKRP Bot's systems.

---

### B. Server ID

Discord Server IDs (Guild IDs) are collected and stored.

Examples of usage include:

* Maintaining server-specific settings.
* Managing server configurations.
* Applying permissions.
* Separating data between communities.
* Maintaining synchronization settings.

Without Server IDs, the Bot would be unable to distinguish between independent Discord communities.

---

### C. Message Content

NKRP Bot may temporarily process Message Content when users interact with bot commands.

Examples include:

* Executing commands.
* Parsing command arguments.
* Performing roleplay actions.
* Generating automated responses.

### Important Clarification

**Message Content is processed only in real-time memory for command execution purposes and is NOT permanently stored.**

Specifically:

* Message Content is **not stored in databases**.
* Message Content is **not archived permanently**.
* Message Content is **not retained as gameplay records**.
* Message Content is **not sold or shared for marketing purposes**.

The Bot reads command-related messages solely to understand what action the user is requesting.

After command execution is completed, Message Content is generally discarded from memory and is not retained as permanent user data.
